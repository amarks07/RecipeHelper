# Nibble Web

This is the Next.js landing page and deployment host for Nibble.

## Structure

- `/app` — Next.js App Router pages (landing page at `/`)
- `/public/app` — Exported React Native app (generated by `npm run build:web`)

## Development

```bash
npm run dev --workspace=apps/web
```

Open http://localhost:3000

## Building

```bash
# Build both mobile and web
npm run build:web

# This:
# 1. Exports the mobile app: expo export -p web --output-dir ./public/app
# 2. Builds Next.js: next build
```

## Deployment to Vercel

1. Push to GitHub
2. Import at vercel.com/new
3. Set **Root Directory** to `apps/web`
4. Vercel auto-detects the npm workspace

The app will be live at your-vercel-domain.com with the mobile app available at `/app`.
